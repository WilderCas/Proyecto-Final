## Descripción del proyecto

Este proyecto consiste en el desarrollo de un juego de **Totito/Tic Tac Toe** implementado en el lenguaje de programación **Python**, utilizando una interfaz gráfica creada con **Tkinter**.

El sistema permite jugar partidas contra una inteligencia artificial que aprende a partir de los resultados obtenidos. Para almacenar y organizar la información del juego se implementan estructuras de datos propias, como lista enlazada, árbol AVL y árbol B.

El objetivo principal del proyecto es aplicar estructuras de datos avanzadas junto con una lógica básica de aprendizaje supervisado y automático, permitiendo que el sistema mejore progresivamente su toma de decisiones.

## Estructuras de datos implementadas

El proyecto utiliza estructuras de datos creadas dentro del código fuente para administrar la información del sistema.

### Lista enlazada

Se utiliza para almacenar información secuencial relacionada con movimientos, historial o registros del sistema.

### Árbol AVL

Se utiliza para organizar información de forma balanceada, permitiendo una búsqueda más eficiente de los datos almacenados.

### Árbol B

Se utiliza para almacenar y organizar registros de forma jerárquica, permitiendo manejar múltiples claves por nodo.

### Sistema de pesos

El sistema utiliza pesos para representar el aprendizaje obtenido durante las partidas. Estos pesos se ajustan según los resultados, permitiendo que la inteligencia artificial mejore sus decisiones con el tiempo.
